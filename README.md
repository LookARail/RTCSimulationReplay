# RTC Schematic Replay

A browser-based replay of RTC simulation history on the modeled track schematic.

Drag a model folder onto the page, or select its matching `.NODE`, `.LINK`, `.HISTORY`, and `.ROUTE` files. Files can be added a few at a time; the model loads once all four are present. The network and internal node mapping are derived from those files, and HISTORY records are checked against ROUTE before replay. Model files are processed locally in the browser and are not uploaded.

RTC times are treated as UTC and shown in Eastern time (fixed UTC−5). Train positions between recorded nodes are interpolated. The replay can include warm-up and cool-down runs. The application is static and can be hosted from the repository root on GitHub Pages.

The stringline button (or <kbd>S</kbd>) opens a time–distance diagram beside the map. Choose a From and To location (in any subdivisions): the diagram follows the shortest connected track path between them, chaining each subdivision's field mileposts end to end where the path crosses into the next subdivision, with a dashed rule at each boundary. Subdivisions, locations and mileposts come from the NODE file and connections from the LINK file; the two ends of the subdivision with the most recorded movements are shown first, and the plotted corridor is highlighted on the map. Train symbols are labelled along their lines where there is room. It uses the same Eastern clock, train filter, selection and hover as the map: clicking a line selects that train and moves the replay to that time, and the replay time is drawn as a vertical line. The wheel zooms time (over the location axis, or with Shift, it zooms distance); drag to pan (distance stays within the corridor, so at full extent dragging only moves time) and double-click to show everything. Lines stop at subdivision boundaries, missing markers or missing links; separate tracks can share a milepost, so crossings alone do not identify conflicts.
